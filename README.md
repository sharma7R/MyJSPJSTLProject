# Employee Management System

## 📌 Project Overview

The **Employee Management System** is a web-based Java application developed to manage employee records efficiently. The application allows users to perform basic **CRUD operations** such as adding, viewing, updating, and deleting employee information.

## 🎯 Purpose

The main purpose of this project is to provide a simple and efficient way to manage employee details digitally instead of maintaining records manually.

## 🛠️ Technologies Used

* **Java**
* **JSP (JavaServer Pages)**
* **Servlets**
* **JDBC**
* **MySQL**
* **HTML/CSS**
* **Apache Tomcat**
* **Eclipse IDE**

## ✨ Features

* Add new employee details
* View employee records
* Update employee information
* Delete employee records
* Store employee data in MySQL database
* Connect Java application with MySQL using JDBC

## 🔄 Application Flow

```text

```

## 🚀 How to Run

1. Install **JDK** and **Apache Tomcat**.
2. Install **MySQL**.
3. Create the required database and employee table.
4. Configure the MySQL database connection in the Java/JDBC code.
5. Import the project into **Eclipse**.
6. Configure the project with **Apache Tomcat**.
7. Run the application on the server.
8. Open the application in a web browser.
